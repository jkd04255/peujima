## 1. 구현 범위
1. 기존 병원 카드의 시간 선택 버튼 UI를 모바일/PC **가로 7일 날짜 스트립 + 세로 시간축 타임라인**으로 교체.
2. PC에서는 왼쪽 병원 정보/수의사, 오른쪽 캘린더 카드. 모바일은 병원 정보 → 의료진 → 캘린더를 세로 배치.
3. 날짜별 가상 슬롯 수, 가능한 시각, 선택됨/선택 불가를 텍스트와 색으로 구별.
4. 다인 의료진 병원은 담당자 선택 전 슬롯을 표시하지 않으며, 변경 시 이전 시각 선택을 해제.
5. 날짜/주간 변경 시 선택된 시각을 초기화하고 각 병원의 주간 이동을 독립적으로 관리.
6. 시간 선택 후 **'선택 확인'** 버튼을 통해 기존 예약 목적·기타 직접입력·시연 완료·보험 안내 이동으로 연결.
7. 사용자가 요청한 2026-11-13(금) 13:00 선택 동작을 시연하기 위해 가상 포근한 동물메디컬센터의 이하린 수의사 금요일 슬롯에 13:00 예시 시간 하나를 추가함.
8. 가상 병원/의료진/시간표 및 실제 예약 불가 안내를 각 캘린더에 표시.

**제외:** 실병원 예약, 실제 영업시간/수의사, 데이터베이스, 로그인, 위치정보 수집, 보험사 API, 결제, 새로운 병원 상세보기.

## 3. 재현 방법
- 브라우저 테스트는 로컬 Chromium + Playwright Python 실행.
- 테스트 날짜/시간을 `2026-11-07 13:00 Asia/Seoul`로 고정.
- 가상 **포근한 동물메디컬센터 → 이하린 수의사 → 11월 13일 → 13:00**를 선택.
- 하단 '선택 확인' → 기존 예약 모달 → 기타(직접 입력) 선택 → 빈 입력 경고 → 진료 내용 입력 → 완료 화면 → '이어서 펫보험 알아보기' 클릭.
- 이후 날짜와 수의사를 바꿀 때 이전 시간 선택이 해제됨을 확인.
- 일요일(11/08)에는 슬롯 없음 메시지/선택 확인 비활성화를 확인.
- 다음 7일 이동 시 해당 병원만 이동하고 다른 병원은 기존 날짜 유지됨을 확인.
- 세로 시간표의 빈 시간은 예약 가능한 슬롯이 아니며, 오전/오후 시각 레이블·가로 눈금으로 구분함.

## 5. 남은 위험과 QA
- **실제 iPhone Safari 기기 테스트는 아직 수행하지 않음.** 사용자가 화면을 열어 확인할 필요 있음.
- 현재는 단일 HTML의 전체 렌더링 방식이므로 병원/의료진/날짜를 선택할 때 해당 카드 위치를 보존하고 포커스를 복원하지만, 모든 보조공학 조합을 확인한 것은 아님.
- 테스트는 Chromium 기반의 로컬 코드에 대한 것이며 GitHub Pages의 공개 사이트에서 새 기능을 테스트했다고 주장하지 않음.
- 시간표 예시는 현재 날짜/시간 이후인 경우에만 표시됨. 2026-11-13 날짜를 지나면 동일 슬롯은 더 이상 나타나지 않음.
- 현재 상품·보험 안내 내용의 정확성에 대한 독립적 법무·보험사 검수는 이번 QA 범위 외.
- GitHub PR 리뷰에서 코드 차이를 확인하고, 필요하면 수동 실기기 QA 후 G3 게이트에 제출.
