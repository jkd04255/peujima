# PJM-025 · 펫보험 비의료비 보장·청구서류·상품 버전 구분 추가 (2026-11-10)

## 근거 조사 결론

1. DB손해보험 다이렉트 펫블리 공식 페이지는 현재 **2610 상품 소개**와 하단 **2607 가입안내/보장표**가 혼재되어 있다. 동일 페이지의 수치를 특정 가입자가 가입한 `2610` 약관으로 자동 적용하면 안 된다.
2. KB손해보험 `26.07` 강아지/고양이, 일반/다이렉트 상품의 상품 식별코드가 공식 보험가격공시에서 확인됨. 26.01 약관을 26.07 전체 가입자에게 적용하지 않음.
3. NH 2604 검색 상위에 노출된 `nh-insure.co.kr` 및 `n-insure.co.kr`은 NH농협손해보험의 **확인된 공식 보험사 도메인 아님**. 판매 대리점 안내는 공식 보험사 약관 전문 검증으로 표시하지 않음. 관련 항목 모두 **원문 약관 미검증**.
4. KB손해보험은 별도 보험금 청구 안내에서 진료기록부·상병명코드·검사결과지·진료비 세부내역·30만원 이상 청구 시 추가 진단/진료 확인 서류 조건 등을 안내.

## DB에서 발견한 추가 담보 예시 (특약 및 버전 미확정)

- **2026-11-10 정정:** 2610 상품 상단의 영상검사 확대보장(MRI/CT/내시경)은 **연간 1회**, 질병 원인 **최초 30일 경과 다음 날** 개시. 과거 기록의 90일 표기는 같은 화면의 다른 버전/특약과 혼동한 것으로 정정. 항암약물치료 확대는 질병 원인 **90일**이며 연 **6회**. <https://www.directdb.co.kr/ltm/prd/cpnm/custInfoView.do?pdcDvcd=l_pet_dog&searchPdcCd=31119&searchPdcTrtHistCd=00> 기본 의료비에서 지급한 금액 및 자기부담금을 고려해 추가액 계산, 자동 중복 지급 아님.
- 대형견 확대보장(수술 제외) **연 10회**, 표준형 예시 **회당 20만원 한도**. 해당 보상비율·일일한도형 및 대형견 조건 필수.
- 항암약물치료 연 6회, 특정 고액수술 연 1회 같은 확대보장은 **별도 담보 가입**과 기존 지급 보험금을 고려.
- 반려견 장례지원비 계약일 이후 **30일 대기**, 사망 시 지급하는 가입금액의 **가입 2년 미만 50%** 예외.
- 물림사고 행동교정훈련비 맹견 제외, 피해자 **2주 이상 치료 필요 진단** 및 법률상 배상책임 등 요건 충족 시 **사고당 최대 10회, 회당 15만원**(등록업체에서 받은 훈련비).
- 개물림사고 벌금: 맹견 제외, 국내 사고, 관련 법률에 따라 **벌금형이 확정**된 경우, 조문·형의 종류별 별도 가입한도.
- 배상책임, 보호자 입원 위탁비용은 **의료비 실손과 다른 담보**. 대상이 제3자/반려인 등으로 다르며 별도 실제 가입 확인 필요.
- 페이지 내 가입상품명은 2610이나 **동일 페이지의 일부 표/담보 정보는 2607 버전**. 이들 정보를 확인하지 않은 2610 계약에 그대로 적용하지 않는다.

## UX 및 기능 변경

- 기존 보험 14종(7개 보험사)과 진료 45개에 비의료비 및 청구 안내 **7개** 추가 => 총 **52개** 선택지.
- 새 그룹 `기타 보장` — 배상책임, 보호자 입원 시 위탁비용, 장례지원비, **반려견 전용** 물림사고 행동교정·벌금·대형견 확대보장, 청구서류.
- 반려묘 보험에서는 반려견 전용 보장 3종 비노출.
- 소수의 공식 확인 상품(DB, KB 청구)에만 확인된 상세 사항을 안내. 메리츠·현대·삼성·카카오의 해당 **비의료비 특약 존재는 미검증**인 경우 미확인으로 표현.
- NH는 `보험사 원문 미확인`과 **공식 사이트가 아닌 판매 안내 페이지**임을 UI에 표시.
- 보장 결과 상단 `관련 버전 약관 원문 확인` / `공식 상품 안내 기준` / `원문 약관 미확인` 명시. 펼침 패널에서 근거 자료명/버전을 프지마 내부에 표시 (외부 페이지 전환 없음).
- 일반 치료비 항목에만 정부 발표 공개 중간값 사용. 기타보장/청구서류는 질병별 평균 진료비나 보험금 계산 **표시하지 않음**.
- 일반적인 필수 입력 여전히 **보험 + 보장/진료 항목 2개**. 파일 업로드/로그인/보험사 API 없음.
