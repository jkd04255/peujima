## 문제와 목표
직전 PJM-013에서 상단 사진과 큰 푸터는 개선했지만 각 기능 페이지에서
`FIND / 01`, `NEARBY / REAL PLACES`, `EXPLORE / 02`,
`GUIDE / 03`, `PRE-CHECK / 2026`, `VISIT INFORMATION`,
`BOOKING / DEMO` 같은 장식 영어, 같은 취지의 반복 소개가
기능 접근을 지연시키고 발표자료처럼 보이게 했다.

## 구현 범위
1. 주변 동물병원: 중복 상단 큰 소개 블록/영문 번호/배경 박스 삭제.
   검색 기능 내부 제목 `주변 동물병원`만 남겨 실제 검색·GPS·반경·지도·결과를
   즉시 노출한다. `NEARBY / REAL PLACES` 장식 라벨은 템플릿에서 제거한다.
2. 다른 경로: 별도 도입형 `pageHeading` 섹션을 제거하고, 접근성용
   시각적 숨김 h1만 유지해 화면 구조를 보존한다.
3. 홈: 동물 사진/핵심 문구/검색/세 서비스 카드/진료분야의 순서를 유지하며
   카드 높이·상하 간격을 줄인다. 데스크톱 메뉴의 중복 설명 행을 없앤다.
4. 진료과·예약: 진료분야·가상 병원 리스트·의료진·7일 시간표·선택·완료는 유지,
   중복 소개 문장과 장식 영어 마커는 CSS에서 렌더링하지 않는다.
5. 펫보험: 비교 선택/안내/기본 결과 표시와 필수 보험 면책 문구는 유지하면서
   소개글·장식 라벨·과도한 간격을 줄인다.
6. 모달: `LOCATION SEARCH`, `BOOKING / DEMO`,
   `RESERVATION DETAILS` 등의 장식 라벨만 숨긴다.
   제목·입력값·`시연` 표시·완료/보험 이동 버튼·주의 문구는 유지한다.

## 보존 조건과 주의
- 기존 사진/색상/브랜드(전체/강아지/고양이), 모든 라우팅과 탐색 기능 유지.
- 실제 검색 정보와 가상 병원·예약을 분리한다. **실제 예약 불가** 문구는
  가까운 검색 결과 하단·가상 진료 구역·예약 모달에 남긴다.
- 위치 좌표는 실제 검색에만 사용하고 서버에 저장하지 않음. 보험 심사/지급
  확정으로 보이게 만들지 않음.
- 신설 DB/Auth/유료 API/실예약/보험사 API 금지.
- 거대 이미지 data URI가 포함된 `index.html` 자체는 수정하지 않는다.
  기존 시연 기능을 위험 없이 보존하기 위해 외부 네비게이션 레이어의
  HTML 템플릿과 CSS만 변경한다. 구형 문서에 남은 영문 라벨은
  해당 뷰에서 CSS `display:none`으로 완전히 비표시 처리한다.
