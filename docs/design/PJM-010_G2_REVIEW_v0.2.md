## 1. G2 UI 구조

### 모바일 (320 / 390px)
1. 기존 프지마 헤더 및 현재 단계 표시.
2. 병원 정보 요약 카드 + **담당 수의사 선택**(다인 병원 필수).
3. 캘린더 영역:
   - 월/연도 + 이전·다음 7일 조작
   - 요일/날짜를 7열로 배치; 선택된 날짜는 **딥그린 원형**.
   - 선택한 날짜 제목, 남은 예시 예약 시간 수.
   - 좌측 시각 레이블 + 우측 시간선; 슬롯은 라벨 있는 카드로 표시.
   - 세로 스크롤 아래에 선택 날짜/시간·담당자 요약과 계속 버튼.
4. 버튼과 화면 하단의 iOS Safari UI가 겹치지 않도록 충분한 스크롤 여백 확보.
5. 시간이 없는 날에는 '선택 가능한 시간이 없습니다'를 표시하고 다른 날짜/의료진 선택 유도.

### PC (1440px)
- 좌측 고정형 정보 카드: 병원명·가상 데이터 고지·수의사 목록.
- 우측 넓은 달력 카드: 월/이동, 7열 날짜, 세로 시간표, 선택 요약·CTA.
- 900px 이하에서는 세로 카드 스택으로 바꾸고, 화면 폭이 좁을수록 의료진 선택 버튼은 3열 컴팩트 배치.

### 색상·타이포그래피
- 배경 크림색: #F8F6F1 / 카드 #FFFEFA.
- 메인 딥그린: #405B46, 선택 날짜/슬롯/버튼에 사용.
- 예약 가능한 블록: 연녹색 #EFF5ED, 왼쪽 세로 포인트.
- 불가능한 시간: 블록 대신 시간선만 표시하거나 확실한 빈 상태 메시지.
- 기존 프지마 글꼴과 분위기 유지. 장식 번호/불필요한 영어 캡션·이모지 금지.

## 3. 접근성·빈 상태·반응형
- 날짜와 수의사는 버튼 및 `aria-pressed` 상태; 현재 선택을 글자/색으로 모두 표현.
- 예약 가능 시간에는 정확한 시각과 '예약 가능', 선택하면 '선택됨' 텍스트.
- 시간표는 가상 슬롯을 **일정 카드**로 표현; 불가능 시각을 클릭 가능하다고 오해시키지 않음.
- 320 / 390 / 768 / 1440px에서 텍스트 겹침·가로 넘침 없는 반응형.
- 모션 감소 설정(`prefers-reduced-motion`) 반영.
- 일자/수의사 변경 시 선택된 슬롯이 해당 조건에 속하지 않으면 무효화.
- 실제 병원 스케줄, 의사 정보, 보험은 **합성 시연 정보**이며 실제 예약과 연결되지 않음.
- 구현 과정에서 병원별 영업시간, 오전/오후 구분, 과거 시간, 휴진일, 동시성 등 실데이터 상태 처리는 별도 기술 검증 대상.

## 4. 기존 제품의 보호 범위
- 브랜드 전체/강아지/고양이 모드와 모드별 상단 문구.
- 얼굴 사진, 그라데이션, 카드 스타일 및 서비스 안내.
- 병원 검색·진료과·7일 예약 스케줄의 데이터 의미.
- 다인 의료진 선택, 기타 직접 입력, 예약 시연 완료, 병원 사정에 따른 취소 가능성 고지, 보험 안내로 수동 이동.
- 외부 병원/보험사 연동, 서버/DB, 결제 및 데이터 수집을 추가하지 않음.
