상태: **G2 디자인 검토 대기 / 운영 코드 미구현 / G3 배포 미승인**

## 1. G1 승인 사항 및 G2 설계 범위

사용자는 기존 예약 시간 선택 화면을 **상단 7일 날짜 선택 바 + 하단 시간별 세로 캘린더**로 변경하는 것을 승인했다. 이 승인은 기능 범위에 관한 것이며 **G2 화면 최종 승인 또는 구현·공개 배포 승인은 아니다.**

현재 v0.5.2의 예약 데모에서 **날짜·시간 선택 표현만 교체**한다.
- 유지: 강아지/고양이/전체 모드, 병원 검색, 가상 병원 목록, 의료진 선택, 기타 진료 목적 입력, 예약 완료 확인, 병원 사정에 따른 변경·취소 안내, 보험 안내로 수동 이동.
- 유지: 따뜻한 크림·딥그린 팔레트, 산세리프, 별도 장식 숫자·영문 슬로건 없음.
- 범위 제외: 실제 병원 데이터, 예약 확정/취소 서버, 보험 조회, 개인정보 저장, 지도 API, 병원 상세보기 신규 구현.

## 2. 모바일 G2 레이아웃

스마트폰 기준 390px 너비, 320px까지 대응.

```
┌──────────────────────────────────────┐
│ 아프지마라멍           디자인 검토용 │
│ ‹ 병원 목록으로                      │
│ 우리 아이의 진료 시간을 선택해 주세요│
│ ┌──────────────────────────────────┐ │
│ │ 선택 병원·지원 동물·진료분야      │ │
│ │ 운영시간 / 휴진일 요약           │ │
│ └──────────────────────────────────┘ │
│ 담당 수의사                          │
│ [ 이하린 선생님  · 내과·피부      ▾]│
│                                      │
│ 2026년 11월                  ‹    ›   │
│  토  일  월  화  수  목  금          │
│   7   8 [9] 10 11 12 13              │
│                                      │
│ 2026년 11월 9일 월요일   예시 2개   │
│ 오전 9시  ───────────────────────── │
│ 오전 10시 ─ [10:00 예약 가능] ───── │
│ 오전 11시 ─ [11:30 예약 가능] ───── │
│ ... (세로 시간축, 선택 가능)         │
├──────────────────────────────────────┤
│ 선택한 예약 시간     [ 계속  → ]     │
└──────────────────────────────────────┘
```

- 화면 상단은 현재 예약 단계와 선택된 병원을 짧게 요약한다.
- 복수 의료진 병원은 **의료진 선택이 선행**되어야 슬롯이 확정 가능하다.
- 날짜는 7일 단위로 보이며 선택된 날짜를 **딥그린 원 안의 숫자**로 구분한다.
- 한 시간당 얇은 가로선, 예약 가능 시간은 옅은 그린 블록, 선택 후는 짙은 그린 블록.
- 예약표는 세로 스크롤. 선택 요약/다음 버튼은 모바일 하단 안전영역에 고정.
- 휴진일/예약 가능 시간 없음은 흐린 상태와 설명 문구로 표시한다.
- 모바일 Safari의 브라우저 툴바·노치와 겹치지 않도록 safe-area-inset-bottom 적용.

## 3. PC G2 레이아웃

1440px 데스크톱: **왼쪽 병원·의료진 카드 / 오른쪽 날짜·시간표**로 구성.

```
┌────────────────────────────────────────────────────────────────┐
│ 아프지마라멍               병원 선택 → 예약 시간 → 진료 내용 │
│ 우리 아이의 진료 시간을 선택해 주세요.                       │
│ ┌────────────────────┐ ┌───────────────────────────────────┐ │
│ │ 포근한 동물메디컬  │ │ 예약 가능한 날짜와 시간            │ │
│ │ 진료 대상·운영시간 │ │ [7일 날짜 바  ←  →]               │ │
│ └────────────────────┘ │ 11월 9일 월요일                    │ │
│ ┌────────────────────┐ │ 오전 9시 ─────────────────────    │ │
│ │ 담당 수의사 선택   │ │ 오전 10시 ─ [10:00 예약 가능]     │ │
│ │ ○ 이하린           │ │ 오전 11시 ─ [11:30 예약 가능]     │ │
│ │ ○ 박도윤           │ │ ...                            │ │ │
│ └────────────────────┘ ├───────────────────────────────────┤ │
│                        │ 선택 날짜·시간  [진료 내용 입력]    │ │
│                        └───────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

- 의료진 전환 시 오른쪽 같은 날짜의 슬롯을 다시 계산하고 이전 시간 선택을 해제한다.
- 병원 메타 정보는 현재 시연 데이터에만 근거하며, 검증되지 않은 리뷰·실시간 영업 여부를 만들지 않는다.
- 690px 이하에서는 모바일 단일 열로 전환한다.

## 4. 컬러·타이포그래피·간격

기존 v0.5.2와 일치하는 계열이며 디자인 전용 기준값.

| 요소 | G2 제안 |
| --- | --- |
| 배경 | #F7F5F0 / #FAF9F6 크림 |
| 기본 글씨 | #27332B |
| 활성 날짜/시간 | #3C4E3E 계열 딥그린 |
| 예약 가능 블록 | #E5EEE5 연녹색 및 테두리 |
| 시간 가이드 | #E0E4DB 옅은 회색-녹색 선 |
| 보조 안내 | #7E847D |
| 경고·시연 고지 | 짙은 갈색 #A37F6D, 텍스트와 함께 |
| 글꼴 | 기기 기본 산세리프/Apple SD Gothic Neo/Pretendard 폴백 |
| 카드 | 반경 12–24px, 부드러운 그림자 |
| 터치 영역 | 버튼 최소 44×44px 목표 |

숫자를 제거하자는 기존 사용자 요청은 **장식용 영문 인덱스**에 관한 것. 날짜·시간·예약 단계 같은 기능적 숫자는 유지한다.

## 5. 상태 정의

| 상태 | 표시 | 전환 규칙 |
| --- | --- | --- |
| 첫 진입 | 병원명·의료진·오늘부터 7일(프로토타입은 고정된 날짜 샘플) | 실제 버전은 병원 현지 날짜 사용 |
| 의료진 미선택 | 선생님 선택 안내·시간 비활성 | 복수 수의사 병원은 필수 |
| 의료진 변경 | 이전 시각 선택 해제 | 새 의료진·날짜의 시간표로 즉시 갱신 |
| 날짜 선택 | 활성 날짜 강조, 헤더 변경 | 선택한 날짜 슬롯만 표시 |
| 가능 시간 선택 | 짙은 그린 블록과 선택 시각 표시 | 다음 단계 활성화 |
| 휴진/슬롯 없음 | 빈 상태 메시지 및 다른 날짜 안내 | 불가 시간은 예약 불가 |
| 다음 7일 보기 | 날짜 바 갱신, 이전 시각 선택 초기화 | 지난 날짜는 예약 불가 |
| 진료 내용 단계 | 기존 목적 선택+기타 직접 입력 | 이번 G2 화면에서는 연결 방식만 명세 |
| 완료/보험 | 기존 예약 완료(시연), 보험으로 선택적 이동 | 자동 이동 금지 |

## 6. G2 UI 목업 (독립 파일)

- [booking_calendar_g2_prototype.html](../../design/prototypes/booking_calendar_g2_prototype.html)
- 이 HTML은 **디자인 테스트용 인터랙티브 목업**이며 프지마의 운영 소스 `index.html`과 분리된다.
- 합성 병원 ‘포근한 동물메디컬센터’, 이미 존재하던 가상 수의사 ‘이하린 / 박도윤’ 예시를 사용한다.
- 디자인 검토를 위해 예약 버튼은 실제 예약·보험 이동 기능 없이 경고창으로만 반응한다.
- 원본 개인 일정이 들어 있는 iPhone 캘린더 사진은 저장소에 올리지 않았다.
