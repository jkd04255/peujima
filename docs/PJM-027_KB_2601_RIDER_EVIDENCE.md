# PJM-027 · KB 다이렉트 26.01 부가보장 원문 대조 및 화면 근거 강화
기준일: 2026-11-10

## 배경과 범위

보험사·상품 버전별 기존 52개 탐색 항목은 그대로 유지한다. 사용자 필수 입력은 보험 상품 + 진료/보장 항목 **2개만** 사용한다. 새 약관 PDF 확보가 어려운 26.07·DB 2610·NH 2604는 기존 미검증 구분 유지. 새롭게 **KB 다이렉트 금쪽같은 펫보험(강아지)(무배당)(26.01)** 본문에 실제 있는 부가 특약 3개만 조항 단위로 구조화한다.

## 공식 원문 자료

- 발행사: KB손해보험, 2026년 1월 약관 / 상품 식별 `(25064)_202601`.
- 공식 PDF: https://direct.kbinsure.co.kr/dwlddoc/KB_Direct_LngtrmDog%2825064%29_202601.pdf
- 검증: 공식 PDF 텍스트+해당 인쇄면 이미지 육안 확인(19·153·167쪽). **26.07의 일반형/다이렉트형 약관이 아님.**
- 26.07 상품 존재와 채널 구분: https://www.kbinsure.co.kr/CG803000012.ec (25343/25345/25357/25358). 이 공시는 약관 본문 지급 조건을 보증하지 않는다.

### 안전장치
- **26.01 원문 조항**은 해당 반려견 상품의 이 세 항목에만 연결된다. KB 반려묘, KB 26.07 일반/다이렉트, 다른 보험사의 동일 부가보장으로 복사 금지.
- 화면에 각 조항의 **인쇄면과 상품 버전**을 노출하고, 기존 26.01↔26.07 차이 경고를 유지한다.
- `A · 일부 약관 원문 확인`은 이 조항의 출처 확인이며 **특약 가입·면책 경과·보험금 지급 확정이 아님**.
- 위탁비·장례비·배상책임은 질병 치료비 실손 계산에 섞지 않음. 기존 DB/메리츠 합성 예시 값 변경 금지.
