# PJM-022 — DB손해보험 펫블리 반려견 2610 공식 상품 안내 확장

## 목표 / 승인 범위
- 사용자가 **가입 보험과 치료 항목 2가지만 선택**하면 프지마 화면에서 대표 진료 항목 공개 중간값 및 해당 상품의 보장 조건과 산식 예시를 확인한다.
- PJM-021 메리츠 반려견 기능/사진/서체/지도/시연 예약/기존 UI는 보존한다.
- 가입 버전과 특약을 확인하지 못한 경우 실제 보험금이 아니라 **한도 적용 전 가상 산식**을 보여준다.
- 외부 홈페이지로 무조건 이동시키지 않고, 상세 조건은 인앱 펼치기에서 본다.

## 근거 (2026-11-10 열람)
1. DB손해보험 공식 다이렉트 페이지: https://www.directdb.co.kr/ltm/prd/cpnm/custInfoView.do?partner_code=L329&pdcDvcd=l_pet_dog&searchPdcCd=31119&searchPdcTrtHistCd=00
   - 페이지 내 상품 표기: **무배당 프로미라이프 다이렉트 펫블리 반려견보험2610(CM)**.
   - 해당 의료비 특약 가입 시 보상비율은 50%/70% 중 선택, 적용 자기부담금은 3만원/5만원 중 선택.
   - 공식 설명의 기본 산식: `(피보험자가 부담한 의료비 - 적용 자기부담금) × 보상비율`과 일일 보상한도 중 작은 금액.
   - 질병: 계약일로부터 **30일 경과 후 다음 날**. 슬관절/고관절 탈구 및 유사 질병 또는 상해: **1년 경과 후 다음 날**.
   - 별도 확장보장: 치과·구강질환, 특정피부 약물치료, MRI·CT·내시경 등은 해당 특약 가입 조건을 확인해야 한다.
   - 공식 페이지는 **상품 안내**이며 가입자 보험증권 및 약관 PDF 전문 검토가 아니다.
2. DB손해보험 다이렉트의 별도 검색 노출 페이지에는 2607(CM) 상품 소개가 혼재한다. **2607 상품의 수치 한도는 2610에 자동 승계하지 않는다.** 가입시기별 계약 차이를 보존한다.
3. PJM-021의 2025년 전국 동물병원 진료비 공개 중간값을 재사용한다. 각 항목별 중간값은 질병별 평균 비용이 아니다.
   - 출처 기록: [PJM-021 근거](PJM-021_INSURANCE_EVIDENCE.md).
   - 정부 원문: https://www.mafra.go.kr/bbs/home/792/592824/download.do

## 계산 예시와 한계
- **입력은 딱 두 개**. 가입시점/플랜/영수증/병력은 묻지 않는다.
- DB 2610 의료비 특약 가입, 해당 진료비가 전부 보장대상, 자기부담금 3만원, 보상비율 70% 또는 50%를 가정하여 **일일·연간 한도 적용 전 금액**만 계산한다.
- 질병: 초진 1만원 + 전혈구 3.4만원 + 혈액화학 8만원 = 가상의 12.4만원 진료 → 70% 65,800원, 50% 47,000원.
- 소화기: 초진 1만원 + 혈액화학 8만원 + 초음파 5.7만원 = 가상의 14.7만원 진료 → 70% 81,900원, 50% 58,500원.
- 외상/관절 검사: 초진 1만원 + X-ray 4.5만원 = 가상의 5.5만원 진료 → 70% 17,500원, 50% 12,500원.
- 각 금액은 **실제 지급 예상/확정금이 아님**. 개인 계약의 1일·연간 한도, 3만/5만원 공제 선택, 각 특약, 보장 대상 판단, 면책, 중복계약, 기지급보험금은 적용하지 않았다. 실제 지급액 0원 가능.
- 피부, 귀, 치과, MRI·CT는 질환별 필수 처치비 및 특약/한도 확인 부족으로 **보험금 금액 표시하지 않음** (귀는 질환의 일반 설명만).
- DB 반려묘, 현대해상 등 다른 상품에는 DB 2610 산식을 복제하지 않는다.
