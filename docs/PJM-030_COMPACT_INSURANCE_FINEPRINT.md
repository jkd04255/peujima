# PJM-030 — 프지마 보험 결과 가독성: 부가 설명은 맨 아래로

## 목적
사용자가 전달한 iPhone 스크린샷에서 “표시 금액은 2025년 전국 동물병원 개별 항목 중간값입니다...”가 **비용 항목과 보험 예시 사이에서 크게 노출**되는 문제를 확인했다. 기존 정보 자체는 중요하지만, 질문의 답보다 주의문이 먼저 읽히는 레이아웃은 지양한다.

### 기존
- 진료비 중간값 출처, 통계상의 제한, 보험사별 약관 버전, 면책 주의, 가상 계산 가정, 근거 등급, 청구 안내가 각 결과의 중간·말미에 혼재.
- 동일 결과에 최대 3개 이상의 별도 접이식 상세 화면이 흩어져 가독성을 해침.
- 스마트폰에서 설명이 핵심 진료비보다 길게 눈에 띔.

### 변경
**보험 보장 요약 → 상품별 핵심 조건 → 진료비 숫자·가상 금액(해당 시) → 결과 맨 아래 '추가 안내 · 출처와 계산 기준 보기' 하나만 표시.**

추가 안내는 기본적으로 접혀 있고, 누르면 작은 글씨로 아래 자료를 모아 확인할 수 있다.

1. **진료비·가상 계산 기준**: 2025 전국 동물병원 항목별 중간값의 의미, 공개 통계가 없는 부가 비용, 가상 계산 가정 및 지급액 미확정.
2. **가입·보장 유의사항**: 부가특약 가입 필요성, 중요한 면책·서류·잔여 한도, 참고 정보의 한계.
3. **보험 상품 버전과 출처**: 검증 등급, 검토한 약관 버전, 26.01/26.07·DB 2610/2607 차이, KB 26.07 공식 상품코드, 원문 미검증 경고.
4. **약관·한도·청구 조건**: 기존 '한도·면책기간·특약 자세히 보기', '근거와 확인할 조건 보기', 플랜별 상세 한도, KB 장례/위탁/책임 특약 원문 면책 등은 삭제 없이 그 안에 유지.

**안전한 기본 화면**
- 실제 진료비 항목 가격과 '가상 예시 · 지급 확정 아님' 표시는 계속 즉시 확인 가능.
- 선택한 치료에 직접 관련된 보장·면책 요약을 포함하는 `pjm023-focus`는 계속 메인에 남김.
- 보험금 자동 지급 확정·진단·실보험사 청구 기능 추가 없음.
- 약관 미검증 상품의 보험금 계산 차단 및 기존 합성 메리츠/DB 계산값 유지.
- 보험/치료 2개 입력과 종 선택, 디자인·사진·지도·예약 기능 전부 유지.
- 모든 부가 정보는 **삭제나 복제하지 않고 기존 DOM 노드 하나를 마지막 보조 설명 영역으로 이동**하므로 이전 보험사 정보 누출·중복 노출 차단.
- iPhone Safari 키보드/터치 접근성을 위해 `<details><summary>` 네이티브 토글을 사용한다. 11px 작은 보조문은 사용자가 펼칠 때만 읽는다.
