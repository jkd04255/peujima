## 1. 개편 이유와 참고
이전 홈 화면은 사진 히어로, 슬라이드식 서비스 바로가기, 진료과 목록, 실제 지도와 가상 예약·보험 화면이 한 페이지에 함께 있어 첫 방문자가 서비스 위치 및 **실제 장소 vs 가상 예약**을 이해하기 어려웠음.

- 참고 UX 패턴: 강남언니의 카테고리·시술/병원 탐색, 병원 정보와 부가정보를 구분하는 페이지 구성, 모두닥의 검색·후기·예약 중심 탐색. 특정 레이아웃·이미지·색·문구·코드를 복제하지 않음.
- 강남언니 예: https://www.gangnamunni.com/hospitals/1850
- 모두닥: https://www.modoodoc.com/
- 프지마는 강아지·고양이·전체 모드 / 차분한 한국어 타이포그래피 / 기존 반려동물 사진을 보존하고, **검증되지 않은 평점·후기·예약 가능 시간·실제 예약 기능을 새로 만들지 않음.**

## 2. 새로운 내비게이션 맵

| 영역 / URL hash | 버튼을 누르면 | 실제/가상 구분 |
| --- | --- | --- |
| 홈 / #home | 지역 검색 · 내 위치로 병원 찾기 · 핵심 서비스 선택 · 진료과 바로가기 | 실제 검색과 시연 기능을 구분 |
| 병원 찾기 / #nearby | 카카오 Places 지도, 거리순, 지역명·GPS·1/3/5km, 상세 링크·전화 | **실제 카카오 장소 검색**, 프지마 예약 불가 |
| 진료과·예약 / #clinics | 진료과 카테고리 → 가상 병원 5곳 → 의사/날짜/시간/예약 시연 | **가상 병원·예약 시연**, 실제 예약 접수 안 됨 |
| 펫보험 / #insurance | 상품/진료 항목별 안내 및 조건 사전 확인 | 안내용, 보장·보험금 지급 보증 아님 |

- 데스크톱: 화면 위에 고정되는 서비스별 탐색 메뉴(현재 위치 표시).
- 모바일/태블릿 850px 이하: 화면 아래에 지속 노출되는 **4개 서비스 탭**. 위쪽에는 브랜드와 반려동물 모드(전체/강아지/고양이).
- 브라우저 URL hash 및 뒤로가기/앞으로가기 지원. 로그인·서버·DB 불필요.
- 제목·설명·상태 고지·카테고리 버튼은 아이콘 대신 **텍스트 우선**. 이모티콘/새 일러스트 없이 절제된 스타일.
- 홈 첫 화면: 지역 검색 폼 + GPS 버튼 → 실제 병원 검색, 이후 실제 장소/가상 체험/보험 카드, 진료과 바로가기.
- 기존 포토리얼 강아지·고양이 사진은 홈 아래의 브랜드 스토리 히어로로 보존. 이전 히어로의 **중복 검색/슬라이드/모드 UI만 숨김**.
- 실제 병원 탭으로 이동하기 전에는 GPS를 요청하지 않음. 사용자가 직접 클릭할 때만 기존 Kakao SDK를 호출함.

## 3. 기술/파일
- index.html: 각 화면을 조건부로 렌더링, hash history, 기존 버튼의 목적지를 새 화면에 연결.
- pjm013-navigation.js: 메뉴, 모바일 하단 탭, 홈 서비스 허브, 화면별 소개 및 가상/실제 안내.
- pjm013-navigation.css: 프지마 고유 타이포그래피·색상·반응형 탐색 메뉴·초점 표시·접근성.
- scripts/build_pages.py: Pages의 기존 Secret 기반 public JS key 빌드에 신규 JS/CSS를 포함. **Admin/REST 키 사용 금지**, 유료 API 변경 없음.
- scripts/ios_safari_lan.py: 기존 로컬 HTTPS 검증도 신규 JS/CSS를 함께 제공.
- PJM-011/012 기존 실예약 금지 정책, 7일 예약 시연, 보험 안내, 카카오 지도 로직은 보존.
