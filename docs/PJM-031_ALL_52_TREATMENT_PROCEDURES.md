# PJM-031 — 보험 진료 52개 항목별 실제 세부 검사·치료·수술 구성

작성: 2026-11-11 | 범위: 프지마 보험 화면 | 기준: PJM-030 수동 배포 완료 `main`

## 사용자 요청

“슬개골의 경우 슬개골 수술도 있고 암의 경우 암수술이나 암치료비 이런 항목들이 없잖아 모든 항목에 대해서 이렇게 세부적인 내용들을 추가해 주세요.”

기존 프지마는 보험/치료 **2개 선택**으로 보험 상품의 기본 보장 안내와 **질환별 세부 처치가 아닌** 일부 공개 진료비 중간값을 보여 주었다. 따라서 실제로 유의미한 **질환별 치료 방법 목록(검사·시술·수술·약물·입원·재활·추적관리)**을 보험 계산 영역과 분리해 제공한다.

## 적용 범위

- 기존 기본 선택지 10개 + PJM-023 확장 선택지 42개 = **총 52개 전부**.
- 세부 항목 **261개**를 독립된 `pjm031-care-procedures.js`에 구조화: `[단계, 진료·치료 명칭, 실제 시행 목적, 공개 항목과 정확히 일치하는 경우에만 medianKey]`.
- 반려견 슬개골: 정형외과 촉진·X-ray, 비수술적 진통·체중·운동 관리, 도르래고랑 성형/경골조면 이동 등 교정수술, 동반 십자인대·뼈 이상 수술, 수술 후 재활·재검.
- 종양·암: 세포·조직검사, 영상·병기 평가, **종양 절제·암수술비**, **항암약물치료비**, 방사선치료비, 면역·표적 치료, 완화·재진 관리.
- 다른 예: 이물 섭취 시 내시경 제거/장절개·위절개, 십자인대 TPLO·TTA, 골절 정복·금속 고정, 디스크 감압, 심초음파·심장약, 각막·녹내장 안과 수술, 고양이 요도폐색 도뇨·입원·요도루조성술, 구내염 발치, 복막염 항바이러스 관리.
- 일반 진료가 아닌 기타 보장(배상책임·위탁비·장례비·개물림사고·청구서류 등)도 빠뜨리지 않고 단계별 서류·사고 요건·지급 한도 확인 항목을 별도로 구성.

## 비용 원칙 — 수술비·항암비를 꾸며내지 않는다

2025년 농림축산식품부는 전국 **3,950개 동물병원**의 **진찰·상담·입원·백신·혈액·영상·투약/조제 등 20개 표준 항목**에 대한 중간값을 발표했다. **질환별 전체 치료비, 슬개골 교정수술, 종양절제·항암 약제·방사선 치료비는 해당 공식 발표의 전국 중간값 대상이 아니다.**

- 기준 원문: <https://mafra.go.kr/home/5109/subview.do?enc=Zm5jdDF8QEB8JTJGYmJzJTJGaG9tZSUyRjc5MiUyRjU3NjIzNiUyRmFydGNsVmlldy5kbyUzRg%3D%3D>
- 코드에 이미 검증되어 있던 **단일 진찰·검사 항목**(`first`, `cbc`, `chem`, `xray`, `ultrasound`, `ct`, `mri`, `inpatient`, `vaccine`)과 정확히 일치할 때에만 같은 공개 중간값을 표시한다. **별도 검사 2개를 하나의 패키지 가격으로 합산하거나, 검사 중간값을 수술비로 표시하지 않는다.**
- 수술·내시경 처치·종양 제거·항암약물·방사선·재활 등 근거가 없는 개별 비용은 **‘수술·시술비 별도 확인’ 또는 ‘병원별 비용 확인’**.
- 기타 보장(배상책임·위탁비·장례지원 등)은 **‘계약·특약별 확인’**으로 표기. 보험금 계산 없음.
- 반려견 전용 공개 비용(반려견 1일 입원비, 반려견 종합백신)을 반려묘 화면에서 아예 숨긴다.
- 병원·지역·중증도·수술 방식·입원 기간에 따른 실제 총비용과 지급액은 확정할 수 없다.

## UI/UX

- 기존 **보험 선택 / 궁금한 치료·검사 선택 / 보장 내용 확인** 흐름에 새로운 필수 입력은 추가하지 않는다.
- 요약과 상품별 핵심 보장 정보 아래, **‘세부 검사·치료 항목’** 블록에 4~7개 간결한 행(모바일 1열, 넓은 화면 2열)으로 각 단계·정확한 명칭·목적·근거 가능한 비용 표시.
- 기타 보장에서는 ‘관련 보장·청구 세부 항목’으로 문구가 바뀐다.
- 전형적 치료 목록이 **필수 치료 묶음이나 질환별 총 치료비가 아니라는 주의사항**은 PJM-030에서 승인한 결과 맨 아래 **‘추가 안내·출처와 계산 기준 보기’** 안으로 이동.
- 공개 약관 근거 등급, 출처, 가입 버전, 실제 지급 불확실성과 기존 보험금 합성 예시는 **절대 변형하지 않음**.
- 변경 파일: `pjm031-care-procedures.js`, `pjm019-insurance.js`, `pjm019-insurance.css`, `index.html`, `scripts/build_pages.py`, `tests/test_pjm_012_build.py`, QA, 문서.

## 후속 검증 과제
- 공신력 있는 병원별 공개 진료비 사례가 충분히 확보될 경우 **출처·병원명·진료 조건이 명확한 경우에만** 세부 수술의 견적 예시를 별도 단계로 도입. 공개 전국 중간값인 양 표시하지 않는다.
- 실제 가입 보험의 진료별 수술/항암 특약 해당 여부는 **계약 버전·서명된 약관**과 교차 대조한 후 별도 작업으로 검증.
