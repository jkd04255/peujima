# PJM-015 · 중복 섹션 전면 제거

2026-11-10 사용자가 iPhone 캡처 3장으로 지적한 `FIND / 01`, `EXPLORE / 02`, `GUIDE / 03` 대형 안내 블록 및 `NEARBY / REAL PLACES`와 주변 동물병원 중복 제목을 제거하는 후속 수정.

## 현황 확인
- 작업 기준: main `8766ee3620cb82c0a6b1f1d32daae2ece3291aa4` (PJM-014 PR #11 병합본).
- 2026-11-10 확인 시 공개 Pages의 마지막 배포 작업은 PJM-013 코드 `35ddc68`이므로, 사용자가 본 큰 3개 소개 블록은 이미 PJM-014 main에서 제거됐으나 미배포된 상태.
- PJM-014에는 주변 동물병원 기능 안쪽의 `.nearby-head` 제목과 실제 장소 배지가 남아 있었음.

## PJM-015 구현
- 카카오맵 실제 장소 검색 화면의 `.nearby-head` 전체를 DOM에서 제거.
- `#nearby-hospitals`에 `aria-label="주변 동물병원 검색"`을 부여하고 PJM-014의 숨김 `h1#pjm013PageTitle` 유지.
- 화면 상단에서 바로 GPS/지역 검색/반경/지도/목록 접근.
- PJM-014에서 기존 제거된 3개 대형 인트로는 재추가하지 않음.
- 기존 사진·모드·보험 안내·가상 병원 및 예약 달력·실제 장소 검색 유지.
- 실예약 불가/위치 미저장/가상 정보/보험 지급 미보장 안내 보존.

## 검증 및 배포 규칙
- 관련 테스트의 `#nearbyTitle` 이전 선택자는 실제 검색 폼 및 중복 영역 부재 검사로 교체.
- 기능 브랜치의 PJM-014 전체 Chromium/WebKit/axe 및 PJM-011/012/013 회귀 QA 실행.
- 테스트 성공 시 PR 제출; 기존 프로젝트 절차대로 별도 병합·배포 승인을 받음.
- iPhone Safari 실기기 검증은 미확인. 공개 사이트 배포 전까지 이전 화면이 보일 수 있음.
