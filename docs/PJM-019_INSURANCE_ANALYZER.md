# PJM-019 · 내 펫보험 보장 분석기 첫 버전

## 사용자 요구
보험사 사이트로 단순 이동하는 대신, 사용자가 가입한 보험의 상품과 치료 종류, 비용, 계약 조건을 바탕으로 보장 가능 여부와 예상 보장 금액, 약관 근거를 알려주는 방향.

## 이번 구현 범위
- 공식 **메리츠화재 펫퍼민트 Puppy & Family 다이렉트(반려견)** *2026년 공개 상품 안내*의 고급형/기본형/실속형만 수치 계산에 사용.
- 통원·입원의료비Ⅲ 기준: 70%/70%/50%, 통상 1일 30만/15만/10만 원, 수술 당일 250만/250만/200만 원, 담보별 연간 1500만/1000만/700만 원, 영상검사 연간 최초 1회 최대 100만/50만/30만 원. 자기부담금 선택 3만/5만 원.
- 사용자가 직접 선택/입력한 상품·플랜·수술/통원/입원·질환·최초 보험개시일·최초 발병일·기왕증·비용·기지급액으로 *가정 계산 예시*를 제시.
- 질병 최초 30일, 슬관절·고관절 최초 1년, 기왕증, 예방접종/정기검진·미용과 같은 공식 설명의 제외 조건에 관해 안내. 불확실한 경우 계산 보류.
- 메리츠 반려묘, 현대해상, DB손해보험은 상품 선택 가능하지만 **확인된 계약별 지급 규칙이 없으므로 금액 계산하지 않음**.
- 외부 보험사 서버 연결·보험증권 업로드·실제 개인정보 저장·실지급 보장 기능 없음.
- 원본 사진과 기존 병원 검색, 가상 예약, 지도, 내비게이션 기능 변경 없음.

## 산식과 한계 (중요)
일반 의료비에 대해 아래는 실제 보험금 지급을 보장하지 않는 시나리오 계산으로만 제시:

`min(max(0, (보장대상 비용-자기부담금)*플랜 보장비율), 1일 남은 한도, 연간 남은 한도, 영상검사 해당 한도)`

- 이 계산의 공제·비례보상 적용 순서와 실손 중복보험 조정 등은 **가입자별 보험 약관 및 보험사 심사를 직접 확인하지 않아 미검증**입니다. 실제 청구 예상값을 확정해 보여주면 안 됩니다.
- 연간 지급액은 가입자가 입력하는 값으로 신뢰성 검증 불가. 담보별 한도·보험개시일·갱신 계약 예외, 검사 분리 청구·동일 진료일의 복합 치료 등 복잡한 상황도 별도 검토 필요.
- 실제 보험금은 해당 계약의 **개별 약관, 특약, 면책 및 보험사 심사**에 따릅니다.
- 원문 PDF에 대한 전문 추출/AI 판독·가입 계약 증권 확인은 아직 구현하지 않았습니다.
