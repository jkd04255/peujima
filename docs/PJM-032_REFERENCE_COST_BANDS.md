# PJM-032 · 진료·수술·항암치료 비용 대략 범위 제공

기준: 2026-11-11 / PJM-031 총 52개 주제·261개 세부 항목 유지. **진료비가 아닌 보험 보장·서류·책임·벌금 항목에는 진료비를 인위적으로 부여하지 않는다.**

## 왜 필요한가

기존 PJM-031에서는 실제 검사·수술·약물치료 종류는 정확히 나열했으나, 공식 통계가 없는 200개가 넘는 카드 대부분을 ‘병원별 비용 확인’으로 표시했다. 사용자는 개별 질환의 **대략적인 예산 규모**부터 알고 싶어 하므로, 확인 가능한 공개 금액과 참고용 금액 구간을 구분해 안내한다.

## 사용자 화면

- 기존 필수 입력 두 개 **보험 상품 + 진료 항목** 유지. 실시간 가격 조회/병원별 API 호출 없음.
- 기존 정부의 2025년 전국 개별 항목 중간값 데이터는 변형하지 않는다. MRI·CT·X-ray·CBC 등 **딱 해당 항목과 일치할 때만 ‘공식 공개 중간값’**으로 표시.
- 나머지 진료비 또는 서비스비는 숫자로 **‘약 ○만~○만원 / 1회·1일·전체 치료 과정’** 제공한다. ‘공개 사례 참고’는 공개된 개별 병원 요금·보호자 실비·시세 안내를 참고한 넓은 예산 구간이며, **전국 평균이나 실제 진료 견적이 아니다**. ‘예산 추정’은 직접 대응하는 공식 집계 없이 임상 처치 유형을 기준으로 잡은 보수적인 범위로 **시장 통계가 아니다**.
- 실제 진료비가 아닌 배상책임 범위·청구서류·법정 벌금 등의 행정 항목은 **‘보험 보장·청구 조건 (진료비 항목 아님)’**으로 표시해 실재하지 않는 치료비를 생성하지 않는다.
- 병원 공식 평균과 참고 예산의 차이, 마취·입원·퇴원약 및 검사 포함 여부, 총액 합산 금지, 실제 지급액 미확정, 각 질환에 사용한 공개 참고자료 URL은 기존 **맨 아래 '추가 안내·출처와 계산 기준 보기'** 내부에만 넣는다.
- 기존 가상 보험금 지급액 계산과 진단/보장 판단 로직은 절대 변경하지 않는다.

## 근거 등급과 한계

| 표시 방식 | 의미 | 적용 예시 |
|---|---|---|
| 공식 공개 중간값 | 2025 전국 동물병원 진료비 조사의 **단일 항목 중간값**, 기존 PJM-021 코드 숫자 재사용 | 초진, CBC, X-ray, CT/MRI, 체중별 1일 입원 등 |
| 약 … · 공개 사례 참고 | 특정 병원의 공개 예시·소수 사례 또는 비공식 수술·치료비 가이드에서 취합한 **넓은 참고 구간**, 통계적 대표성 없음 | 편측 슬개골 80~300만원, 십자인대 150~350만원, 종양 수술 30~500만원, 항암 약물 1회 20~70만원, 방사선 1회 50~150만원 |
| 약 … · 예산 추정 | 공개 자료에서 해당 세부 항목을 직접 확인하지 못해 검사/치료 유형별로 구성한 **서비스 자체 예산 가정**. 오차 범위가 매우 클 수 있음 | 세포검사·재활·중증 입원·특이 약물 등 |
| 보험 보장·청구 조건 | 진료비 대상이 아닌 행정/법률/보장 요건 | 배상책임 면책, 사고당 한도, 청구서류 |

**중요:** ‘예산 추정’ 구간의 상한/하한은 통계적 신뢰구간도 아니고 모든 진료비를 포함한 견적도 아니다. 실제 수술·항암·입원비는 예상 범위를 넘을 수 있으며, 여러 카드를 더하면 중복 비용이 생기므로 **합산 금지**. 체중·마취·병원 수준·지역·검사 포함여부에 따라 비용 차이가 크다.

## 구현/관리·검증

- `pjm032-cost-bands.js` 데이터: 고비용 치료의 항목별 고정 밴드(쉽게 조절 가능) + 검사·처치·약물 유형별 보수적 예산 밴드. 각 밴드는 `low,high,unit,basis,source` 메타를 가진다. 임상적으로 별개인 치료를 하나로 합치지 않는다.
- 261 세부 항목의 코드 검증: **235개 진료/서비스 비용 밴드**, **26개 비진료·보험 조건**, 미분류 **0개**.
- `pjm019-insurance.js`: 기존 중간값이 있으면 그 값을 최우선; 없는 세부 항목에는 추정 범위를 보여준다. 출처 및 합산 금지 설명은 PJM-030 하단 접이식 안내로 보낸다.
- 반려묘 입원비·반려견 백신의 잘못된 공시 혼용 방지 및 반려견/고양이 중성화 시세 분리.
- `pjm019-insurance.css`: 가격 범위의 가독성 및 11px 수준 부차적인 출처 설명. 
- `index.html`, `scripts/build_pages.py`, `tests/test_pjm_012_build.py`: 새 JS가 **수동 배포 빌드에 포함되는지** 확인.
- `tests/test_pjm_031_procedure_matrix.py`: 기존 가격 근거 안내 검사를 새 참고 범위 UI에 맞게 개선.
- `tests/test_pjm_032_cost_bands.py`: 261개 전수, 235/26 분리, 슬개골·암·항암·방사선·반려묘 중성화·고양이 FIP·장례비, 공식 2025 중간값, 하단 출처·가로 넘침·보험금 계산 불변 검사.
- 전체 Chromium 320/390/768/1440, WebKit 390, axe, 지도/GPS·예약·기존 보험·배포 빌드 회귀 전부 성공할 때만 병합.
