# PJM-026 상품 버전과 증거 등급 — 2026-11-10

## 목표
프지마에서 보험사의 **상품 존재·공개 소개·특정 버전의 약관 원문**을 혼동하지 않는다. 한 상품의 약관을 일부 검토했다고 모든 치료의 보장 여부를 확정하지 않는다. 사용자 입력은 여전히 보험상품 + 진료/보장 두 가지만 필요하다.

## 구현된 UI
- 기존 **보험 상품 14종 / 진료·부가보장·청구 52개** 선택지 유지.
- 결과에서 **근거 등급(A/B/C/D)**, 검토 버전, 해당 보험사에 맞는 주의 사항을 별도 표시.
- DB 2610 vs 2607, KB 26.01 약관 vs 26.07 공시, NH 공식 회사 도메인 vs 판매 대리점 등 주요 혼동 방지.
- 외부 보험사 페이지로 보내지 않고 **프지마 안에서 설명을 완료**한다. 원문 링크는 개발 근거 문서에만 둔다.
- 데이터는 `pjm023-catalog.js`의 `evidence` 객체로 분리. 한 보험사에 새 약관 버전이 확인되면 기존 버전을 덮어쓰기보다 구버전 비교를 추가할 것.
- 고위험 안내: A조차 *모든 치료의 지급 조건을 검증했다는 뜻이 아니라, 특정 버전 일부 조항을 원문 검토했다는 뜻*. B/C/D는 확정 보상 조건 아님.
