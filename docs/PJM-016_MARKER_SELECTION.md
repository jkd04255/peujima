# PJM-016 · 지도 마커 선택 시 동물병원 카드 강조

## 사용자 문제
카카오맵 동물병원 마커를 클릭하면 해당 병원 카드로 자동 스크롤되지만,
위아래의 다른 병원 카드와 시각적으로 구분되지 않아 어떤 병원을 눌렀는지 알기 어려움.

## 승인 범위
- 지도 마커 클릭 → 해당 실제 병원 카드로 스크롤 + 포커스 이동
- 선택된 카드만 초록색 강조 테두리, 연한 초록색 배경, `선택한 병원` 배지
- 다른 마커를 클릭하면 이전 강조 제거 및 새 카드 강조
- 지역 또는 반경 재검색 시 선택 초기화
- 화면 낭독기에서 선택된 카드 이름과 선택 상태를 읽을 수 있도록 접근성 이름 갱신
- 기존 사진/모드/카카오맵 장소 검색, 외부 지도 상세 링크·전화, 가상 예약/보험/필수 고지 모두 보존

## 구현
- `pjm012-nearby.js`: 메모리 기반 `selectedPlaceId`, 단일 선택 처리, 마커 클릭 선택, 검색 시 초기화; DOM 갱신으로 지도를 불필요하게 다시 생성하지 않음
- `pjm012-nearby.css`: 2px 강조 외곽선·절제된 배지·모바일 크기 조절
- `tests/test_pjm_016_marker_selection.py`: 실제 SDK 마커 등록/클릭 콜백을 모의한 Chromium(320/390/1440) 및 WebKit(390) 테스트, 선택 단일성, 포커스, CSS 하이라이트, 검색 초기화, 오버플로, 콘솔 예외 확인
- Github Actions PJM-014 통합 QA에 신규 검증 추가
