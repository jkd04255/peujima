# PJM-021 — 보험사 한 곳씩 검증하는 내부 보장 설명

## 사용자 목적
'보험 상품 + 진료 종류' 두 가지만 입력하고 프지마 안에서 바로 **대표 진료 항목의 공개 비용**, **가상의 보장액 비교**, **면책 조건과 산식 근거**를 확인한다. 사용자를 무조건 보험사 홈페이지로 이동시키지 않는다.

## 검증 범위: 1차 메리츠화재 펫퍼민트 반려견 2026 다이렉트
- 공식 상품·보험사: https://direct.meritzfire.com/pet/product.do
- 2026년 공식 상품 소개 및 '반려견 관련 특약' 상품 설명 기준. 의료비Ⅲ **통원/입원 특약에 가입했다는 가정**.
- 플랜: 고급형 70%, 1일 30만원, 연 1,500만원, 수술 당일 250만원, MRI/CT/내시경 관련 연간 최초 1회 100만원
- 기본형 70%, 1일 15만원, 연 1,000만원, 수술 당일 250만원, 영상검사 관련 연간 최초 1회 50만원
- 실속형 50%, 1일 10만원, 연 700만원, 수술 당일 200만원, 영상검사 관련 연간 최초 1회 30만원
- 자기부담금은 3만원 또는 5만원을 계약에서 선택. 이번 가상 계산 **3만원 공제**를 고정 가정하며 다른 선택을 기본값으로 추정하지 않는다.
- 질병 최초 30일 면책, 반려견 슬관절·고관절 관련 최초 1년 면책(갱신계약 예외 확인), 보험 개시 전 기왕증, 예방 목적 진료 등 면책 안내.
- 본문은 **공식 상품 안내를 검토한 것**이며, 모든 가입 시점의 **약관 원문 PDF 전문** 또는 개별 가입 증권을 대조한 것으로 표시하면 안 된다.

## 수치 출처: 2025년 공식 전국 동물병원 비용 조사
- 농림축산식품부 2025.12.22 보도자료 원문 PDF: https://www.mafra.go.kr/bbs/home/792/592824/download.do
- 조사 대상 3,950개소. 조사 항목은 **각 진료 항목의 전국 공개 진료비 중간값**.
- 초진(전체): 10,000원 / 전혈구 검사: 34,000원 / 혈액화학 검사: 80,000원
- 방사선 X-ray(전체): 45,000원 / 초음파(전체): 57,000원
- CT(전체): 600,000원 / MRI(전체): 791,500원
- 반려견 입원비(전체): 60,000원 / 반려견 종합백신: 25,000원
- **중요: 서로 다른 병원의 항목별 중간값을 단순 합산한 결과는 실제 환자 1인의 평균 진료비가 아니다.** 피부/귀/치과 처치비 등 공개되지 않은 금액은 만들어내지 않는다.

## 인앱 설명 구조
- 입력 2개: 가입 보험 상품, 궁금한 진료. 기존 사용자 흐름 유지.
- 보험 가입 상품: 현재 메리츠 반려견 하나만 **금액 예시** 지원. 다른 회사/반려묘는 결과에 **보험금 미검증** 표시하고 공개 진료비만 안내.
- 사용자 선택 진료: 질병 통원·입원, 구토·설사, 피부, 외이염, 상해, 슬개골·고관절, MRI·CT, 치과, 예방접종, 미용 등.
- '진료 항목 공개 중간값' 옆에 각 비용을 표시. 근거와 제외 조건을 하단 인앱 상세보기로 제공.
- 통원 비수술의 일부 사례만 명시적으로 **가정 예시** 계산:
    - 질병: 초진 + 전혈구 + 혈액화학 = 124,000원 → 70%·공제 3만 가정 65,800원 / 50%·공제 3만 가정 47,000원
    - 소화기: 초진 + 혈액화학 + 초음파 = 147,000원 → 70% 가정 81,900원 / 50% 가정 58,500원
    - 상해/슬개골 검사: 초진 + X-ray = 55,000원 → 70% 가정 17,500원 / 50% 가정 12,500원
    - 모든 산정에 1일/연간 한도 상한 적용. **이 예시의 모든 검사비가 실제로 보장대상이라고 확인된 것은 아니다.** 면책·기왕증·이전 청구액·여러 보험 중복 지급 등을 고려한 *최종 보험금이 아님*.
- MRI·CT의 경우 별도 연간 한도와 기본 일일 한도의 상호작용을 검증하지 못해 **지급액 계산 보류**. 피부·귀·치과 등도 필수 가격 데이터가 없으므로 지급액 미표시.
- 예방/미용은 일반 비보장 안내. 계약상 예외·선택 특약이 있으면 달라질 수 있음.
