# PJM-011 · 병원 상세 화면과 예약 진입 분리 (Feature Spec)

- 날짜: 2026-11-07 (KST)
- 상태: G1 요구사항 승인 / G2 디자인 승인 / 기능 브랜치 구현 및 QA 진행
- 기준선: 프지마 v0.6.0 (PJM-010 캘린더)
- 브랜치: `feature/pjm-011-clinic-detail-flow`
- 저장소 공개 main: **변경 금지 (G3 배포 승인 전)**

## 1. 사용자 문제
현재 병원 검색 결과에 주간 캘린더가 즉시 표시되어 병원을 비교하고 상세 정보를 읽는 과정과 예약 과정이 혼합된다.

## 2. 목표/화면 흐름
1. 검색·진료과 필터로 가상 동물병원 목록 조회.
2. 목록의 병원 카드 선택 → 선택한 병원의 독립적인 상세 화면 열기(병원명·소개·지역·진료과·운영시간·의료진).
3. 상세 화면에서 **'예약하기'** 선택 → 기존 PJM-010 주간 캘린더와 의료진 선택 영역 표시.
4. 의료진(복수 병원 필수) → 날짜·시간 → 선택 확인 → 기존 시연 예약 모달 → 완료/보험 안내 흐름 유지.
5. '병원 목록으로' 이동 또는 '예약 일정 접기'로 취소·되돌리기 가능.

## 3. 범위 및 기술
- 기존 정적 `index.html` 국소 변경: 병원 리스트 카드/상세 view 분리, 화면 상태, 진입 버튼, 반응형 스타일.
- 기존 병원 5곳 합성 데이터, 의료진/슬롯 검증, 예약 내용·기타 입력·보험 시연 로직 그대로 유지.
- 모바일 320/390px/태블릿/데스크톱 반응형 설계, 기존 사진·그라데이션·브랜딩 보존.
- 이번 범위 제외: 실제 병원/의료진 예약, DB, 로그인, 결제, 지도/보험 API, 외부 데이터 연동.

## 4. 인수기준
- AC-011-01: 목록 상태에서 캘린더가 보이지 않고 병원별 상세 진입 버튼을 제공.
- AC-011-02: 병원 선택 시 **해당 병원만** 상세 화면에 표시. 이전 목록으로 되돌아갈 수 있음.
- AC-011-03: 상세 화면의 예약하기를 클릭하기 전에는 주간/시간 캘린더와 의사 선택 컨트롤이 노출되지 않음.
- AC-011-04: 예약하기 선택 시 **선택 병원**의 의료진·7일 날짜 바·세로 시간표 표시. 예약 일정 접기 가능.
- AC-011-05: 예약 시간 선택, 의료진 변경 시 해제, 주간 이동, 휴진/슬롯 없음, 시연 예약 완료, 보험 이동 기존 기능 회귀 통과.
- AC-011-06: 검색어/모드 변경 시 다른 병원의 세부 예약 정보가 섞이지 않음.
- AC-011-07: 320/390/768/1440px에서 가로 넘침·JS 오류 없음 (환경 가능한 경우 로컬 브라우저 QA).
- AC-011-08: 실제 예약 가능 정보로 오인되지 않도록 합성/시연 고지 유지.
