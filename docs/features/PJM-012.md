## 1. 사용자 문제
현재 실제 주변 동물병원을 확인할 수 없고, 5곳의 가상 예약 체험 병원이 실제 위치 기반 탐색처럼 보일 여지가 있다. 기존 지도 버튼은 외부 검색 링크만 제공한다.

## 2. 목표
사용자가 GPS 사용을 **직접 승인**하거나 지역을 직접 입력해, 카카오맵에 등록된 동물병원 장소의 지도·거리순 목록을 확인하고 전화·지도 상세로 이동한다. 실제 병원에 대한 예약 기능은 제공하지 않고, 기존 가상 병원 예약 시연은 구분하여 보존한다.

## 3. 범위
- 기존 히어로·사진·그라데이션·브랜딩·모드/필터/가상 병원 5곳/예약 캘린더/보험 안내 유지.
- 지도 기반 실제 병원 검색을 별도 섹션으로 상단 우선 배치; 기존 가상 병원 리스트에는 명시적 `예약 기능 체험·가상 병원` 표시.
- Kakao Map Web JavaScript SDK `services` 라이브러리, `keywordSearch('동물병원', {location, radius, sort:DISTANCE})`; 1/3/5 km 반경.
- GPS `navigator.geolocation.getCurrentPosition`는 클릭할 때만; 지역 수동 검색(주소 지오코딩 우선, 장소 키워드 보조).
- 최초 15개 결과의 거리순 리스트, 지도 마커, 주소·연락처(존재하는 경우), 카카오 지도 상세 링크.
- 미설정 JavaScript 키, 위치 거절/미지원, 검색 실패, 0건, 권한 거절, SDK 네트워크 오류에 적절한 안내와 외부 지도 검색 대안.
- 연결 전 키값 입력은 테스트용 `sessionStorage`에만 저장(로그인·DB 없음). 최초 실사용 서비스용 키의 등록/배포는 G3 전 사용자 제공 또는 승인 후 별도 검토.
- 서버·DB·개인 위치 저장/분석/로그인·실제 예약/보험/결제/유료 API 활성화 **없음**.

## 4. UX
- 상단 `주변 병원 찾기`는 신규 실병원 검색 섹션으로 이동.
- 주변 병원 섹션: 동의 요청 버튼, 지역 입력, 검색 반경, 상태 메시지, 지도, 실제 검색 결과 및 외부 지도 링크.
- 별도 하단 섹션: 기존 가상 5개 병원의 상세 보기 및 예약 시연. **실제 주변 병원 검색 결과에는 예약하기 버튼을 표시하지 않음**.

## 5. 인수기준
- AC-012-01: 권한 자동 요청 없이 버튼 클릭 시에만 GPS 요청.

- AC-012-03: 지역명 수동 입력으로 위치 거부 시에도 검색 가능; 유효한 검색 결과가 없으면 안내.
- AC-012-04: API 키 미설정·SDK 오류·위치 거부·API 검색 0건에서 명시적 대안; 허위 결과 없음.
- AC-012-05: 기존 가상 예약 병원 5곳과 **실제 검색 결과 명확히 분리**, 실검색 결과에서 시연 예약/실예약 흐름으로 연결 금지.

- 공식 Kakao Map SDK: https://apis.map.kakao.com/web/guide/
- 설정: https://developers.kakao.com/docs/ko/kakaomap/common
- JavaScript SDK 도메인: `https://jkd04255.github.io`, `http://localhost:8000` (사용자 콘솔 등록 필요).
- 무료 쿼터: 개발자 계정 **첫 카카오맵 활성화 앱에만 적용**. 무료 설정 및 무과금 유지.
- REST API/ADMIN 키 금지. 키 없이 라이브 검색 완료로 주장하지 않음.
