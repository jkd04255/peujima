# v0.5.0 — 예약 UX 확장 및 7일 타임라인

기준 디자인: v0.4.1 (사진/색상/로고 유지). 구현: 이 대화의 ChatGPT 직접 작업. Codex 미사용.

## 사용자 요청 반영
- 모바일 헤더: 아이콘만 있던 주변 병원 찾기 버튼에 텍스트 라벨 추가 (매우 좁은 화면에서는 '병원 찾기'로 축약).
- 병원별 오늘부터 7일 예약 타임라인, 가장 이른 예시 시간 및 남은 예시 슬롯 수 표시, 다음 7일 보기.
- 합성 데이터로 만든 다인 의료진 병원 2곳(2명 및 3명), 선생님을 명시적으로 선택해야 시간 예약 가능.
- 진료 목적에 '기타 (직접 입력)' 추가, 미입력 오류 안내.
- 예약 완료 확인 화면에서 병원/날짜/시간/수의사/진료 내용 재확인.
- 병원 사정에 따라 예약 변경 또는 취소 가능 안내.
- 예약 완료 이후 보험 페이지로 이동하는 버튼 제공. 자동 이동 금지.

## 데이터 및 안정성
- 병원·의료진·시간표는 모두 가상의 시연용 데이터.
- 서버/인증/예약 접수/실제 보험조회 연결 없음.
- 예약 완료는 시연이며 실제 예약이 성립하지 않습니다.
- 테스트: Node 데이터 회귀(병원 5곳, 진료과 7개, 보험조합 42개), 가상 수의사 시간표 검증.
- Playwright Chromium 로컬 QA: 390px 예약과 기타 입력 검증, 수의사 선택, 확인 화면, 보험 이동, 모드 전환; 320/390/1440px UI 스크린샷 시각 검토.
- GitHub main의 정적 index.html 배포 코드 확인. GitHub Pages 실제 서버의 배포 갱신 여부는 별도 원격 자동 브라우저 검사 미완료.
