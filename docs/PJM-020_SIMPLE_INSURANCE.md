# PJM-020 — 간결한 보험 보장 요약 UX

## 사용자 피드백
PJM-019는 가입한 보험의 보장 요약을 간단히 받아보려던 목적과 달리 플랜·금액·가입일·병력·기지급액까지 한 번에 요구해 부담이 큼.

## 변경
- 사용자가 답하는 항목을 **보험사·상품 + 치료·검사 종류, 총 2개**로 줄임
- **보장 내용 확인하기** 버튼 아래에 보장 검토 상태, 핵심 요약, 반드시 알아야 할 약관 조건만 표시
- 검증된 메리츠화재 펫퍼민트 반려견 의료비Ⅲ 공개 상품 안내 기준의 플랜별 한도는 **결과 안에서 접는 상세 표**로 표시
- 보장금액 계산기/개인 진료·병력·가입일·지급액 입력 제거. 불충분한 계약 정보로 보험금을 계산하는 기능을 화면에서 사용하지 않음
- 메리츠 반려묘, 현대해상, DB손해보험은 계약별 확인이 필요하다는 안내만 제공; 반려견 한도 전용 적용 금지
- 현대해상 반려견 일부 검사·관절·치과 분야는 보장 특약 유무가 필요하다고 안내
- 예방·미용은 일반적인 비보장으로 안내하되 계약별 확인 가능하도록 함
- 결과 확인 자체가 보험사 사이트 이동으로 연결되지 않으며, 공식 자료 링크는 부수적 근거로만 표시
- 서체 SUIT/SUITE, 사진, 기존 병원·예약·카카오맵 기능 보존

## 정책·정확성
- **메리츠화재 공식 2026년 다이렉트 상품 안내**를 요약한 것으로, 사용자가 가입한 실제 약관 PDF 전체를 자동 판독한 결과가 아님
- 공식 출처: https://www.meritzdirect.com/pet/product.do
- 현대해상 상품: https://m.hi.co.kr/serviceAction.do?menuId=202853
- DB손해보험 안내: https://www.dongbuinsurance.com/FWMALV6783.do
- 결과는 **가입 시점, 가입 특약, 면책기간, 진단, 보험사 심사에 따라 달라질 수 있음**
- 계약번호·병력·결제액·위치·개인정보 수집 및 서버 전송 없음
- 실제 보험금 지급 판단과 계약별 상세 약관 분석은 구현 범위 밖
