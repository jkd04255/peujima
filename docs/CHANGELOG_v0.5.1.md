# 프지마 v0.5.1 — 섹션 전환 그라데이션 및 장식 번호 제거

기준: v0.5.0 정적 HTML. 승인된 반려동물 얼굴 사진·브랜드·예약 시연 로직 유지.

## 변경 사항
- 히어로 아래 서비스 카드부터 진료과, 병원 목록, 보험, 푸터까지 섹션 경계색을 그라데이션으로 연결
- 01 / YOUR PET'S HEALTH, 02 / FIND YOUR CLINIC, 03 / INSURANCE GUIDE 제거
- 서비스 슬라이드의 01 / 04, 서비스 바로가기 01 / SERVICE 등 장식 숫자 제거
- 진료과/병원 카드 인덱스, 보험 섹션의 큰 03, 타임라인/의료진 단계 머릿번호 제거
- 실제 입력 순서(01. 가입한 펫보험, 02. 진료 예정 항목)는 보존
- 모바일 섹션 여백과 카드 높이 소폭 정돈

## 테스트
- 로컬 Chromium Playwright: 320px / 390px / 1440px에서 가로 넘침 및 JS 예외 없음
- 진료과·병원 5곳·일주일 타임라인·다인 의료진 2곳 유지
- 선생님 선택 전/후 슬롯, 예약 모달, '기타' 입력 확인
- GitHub main/index.html에서 업로드 내용을 재조회하여 검증
- 원격 GitHub Pages 렌더링은 접속 도구 제한으로 검증하지 못했음
