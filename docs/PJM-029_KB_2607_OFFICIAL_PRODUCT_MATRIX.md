# PJM-029 · KB손해보험 26.07 네 상품 분리 및 약관 근거 검증
작성일: 2026-11-10

## 결론
**KB 26.07의 상품 존재·상품코드는 KB손해보험 공식 공시에서 확인했습니다. 그러나 원문 PDF 파일 다운로드 주소를 확보한 것만으로 PDF 본문 조항까지 읽고 검증한 것은 아닙니다.** 제3자가 인용한 26.07 약관 해설은 별도의 자료등급으로 저장하고 개별 가입자의 확정 보상조건으로 출력하지 않습니다.

- KB 공식 상품 가격 공시: https://www.kbinsure.co.kr/CG803000012.ec
- 일반형 반려견 25343, 일반형 반려묘 25345, 다이렉트 반려견 25357, 다이렉트 반려묘 25358. 이 네 항목은 **상품코드가 다른 별개 상품**입니다.
- 공식 PDF 다운로드 주소(접근 시 application/octet-stream 형식 반환, 자동 판독 불가):
  - 반려견 일반형: https://www.kbinsure.co.kr/CG802030003.ec?fileNm=25343_1_1.pdf
  - 반려묘 일반형: https://www.kbinsure.co.kr/CG802030003.ec?fileNm=25345_1_1.pdf
  - 다이렉트형 25357·25358은 이번 조사에서 정확한 공식 PDF 주소를 검증하지 못했습니다. 일반형의 문서를 다이렉트형 원문 대신 사용하지 않습니다.
- KB 공식 26.01 반려견 PDF(이미 이전 PJM-024/027/028에서 일부 조항 확인): https://direct.kbinsure.co.kr/dwlddoc/KB_Direct_LngtrmDog%2825064%29_202601.pdf

## UI / 구현 방식

- **2개 선택(보험사 + 진료 항목)** 유지. 14개 상품 선택지·52개 항목·기존 디자인 유지.
- 선택한 KB 반려견 결과에는 "26.07 일반형 25343 · 다이렉트형 25357", 반려묘에는 "일반형 25345 · 다이렉트형 25358" 한 줄 표시.
- 펼치기 전 본문은 **KB 26.01 기존 검증 조항/가입시기 불일치 경고** 유지; 26.07 제3자 해설을 공식 약관처럼 섞지 않음.
- 펼쳐진 상세에는 공시된 26.07 상품코드, 제3자 해설의 검토 예시, PDF 원문 본문 미검증 및 계약 단위 확인이 필요하다는 문구를 구분하여 표시.
- 외부 보험사 링크나 사용자 개인정보 입력 추가 없음. 가입자에게 직접 홈페이지로 이동을 강요하지 않음.
- 증거 구조: `pjm023-catalog.js`의 `kb2607.products` 및 `kb2607.secondary`를 추가. 원문 검증이 완료되면 `secondary`와 별도의 `primaryPolicyClauses`를 신규 정의해 원본 인쇄면·원문 제품코드를 기록해야 함.
