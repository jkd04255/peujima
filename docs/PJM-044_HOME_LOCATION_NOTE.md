# PJM-044 — 홈 위치 확인 안내 간소화

- 기준: `main 6700f025ae526fbccb018aecb9fba2ed543c231d` (PJM-043 / PR #39 병합).
- 변경 종류: 홈 화면 보조 문구 1개만 간결화. 브랜드/UI/정보구조·기능 변경 없음.
- 참조: `AGENTS.md`, `docs/OPERATING_PROCESS_v1.md`, `docs/HUMAN_WEB_DESIGN_ADOPTION.md`, `.agents/skills/human-web-design/SKILL.md`, `.agents/skills/frontend-design/SKILL.md`.
- G2 전체 HOLD 유지. 정확한 PR HEAD 전체 QA와 G3 병합 조건 충족 전 main 병합 금지.

## 확인된 문제
홈 지역 검색 아래 보조 문구는 기존 `카카오맵 실제 병원 정보 · 위치는 버튼을 누를 때만 확인합니다.`였습니다. 같은 화면의 서비스 카드에 이미 `실제 병원`, `가상 체험`이라는 필수 구분이 있어 플랫폼 설명은 반복되고, 모바일에서 확인해야 할 **위치 접근 시점**이 뒤에 숨습니다.

## 한 가지 변경
- 변경 전: `카카오맵 실제 병원 정보 · 위치는 버튼을 누를 때만 확인합니다.`
- 변경 후: `‘내 위치로 찾기’를 누를 때 위치 확인을 시작합니다.`
- 검색 버튼 / 내 위치 찾기 / 지도·거리순 결과, 위치 권한 요청 방식, 실제·가상 병원 구분, 관련 안전 고지 및 보험 문구는 변경하지 않습니다.
- 새 안내, 배지, 아이콘, 카드, 애니메이션, 스타일·브레이크포인트를 추가하지 않습니다.

## 인수기준 및 QA
1. 홈 지역검색 바로 아래 보조 문구는 명료한 위치 시작 안내 한 줄이며 기존 플랫폼 중복 문구가 없습니다.
2. 전체/강아지/고양이 3모드에서 동일하게 보이고 `내 위치로 찾기` 버튼, `실제 병원` / `가상 체험` / `정보 안내` 라벨은 유지합니다.
3. 보험 화면으로 이동 후 홈으로 돌아와도 안내가 정상이며 JavaScript 오류와 가로 오버플로가 없습니다.
4. Chromium 320/390/768/1440px 및 WebKit 320/390px 신규 브라우저 QA, 프로젝트의 PJM-011~043 Chromium/WebKit/axe 통합 QA가 **PR 최신 HEAD**에서 성공해야 병합할 수 있습니다.
5. 신규 320/390px 화면 스크린샷은 Actions artifact에 남깁니다.
